# Рубежный контроль №1 - вариант Б-11

Предметная область: «Программа - Компьютер».

В `main.py` определены классы `Program`, `Computer` и `ProgramComputer` для связей «один-ко-многим» и «многие-ко-многим». Скрипт не требует сторонних библиотек.

Запуск:

```powershell
python main.py
```
